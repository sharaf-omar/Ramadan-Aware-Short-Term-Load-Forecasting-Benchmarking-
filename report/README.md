# Capstone Report — LaTeX Source

The compiled report is built from `main.tex` and `refs.bib`. The
figures are pulled from `../docs/figures/` (set via
`\graphicspath{{../docs/figures/}}` in `main.tex`), so the report
directory itself stays minimal.

## Compile

Easiest way (handles `.aux`, `.bbl`, `.toc` regeneration in one shot):

```
latexmk -pdf -bibtex main.tex
```

If you prefer the explicit toolchain:

```
pdflatex main.tex
biber main             # if biblatex is configured for biber (default)
pdflatex main.tex
pdflatex main.tex      # twice more to settle cross-refs + ToC
```

Compatible with TeX Live 2020+ or MikTeX. Requires the following
packages (all standard, all in TeX Live full):

- `geometry`, `microtype`, `parskip`, `setspace`
- `fontenc`, `inputenc`
- `graphicx`
- `amsmath`, `amssymb`, `amsthm`, `siunitx`
- `booktabs`, `multirow`, `array`, `makecell`
- `caption`, `subcaption`, `float`
- `xcolor`, `tcolorbox`
- `fancyhdr`, `titlesec`
- `hyperref`, `cleveref`
- `biblatex` (with `biber` backend; fall back to `bibtex` if
  needed by editing the `biblatex` options)

## Files

| File | Purpose |
|------|---------|
| `main.tex` | Single-file source for the entire report (~30 pages) |
| `refs.bib` | Bibliography (TSFMs, classical methods, statistics, data sources) |
| `main.pdf` | Compiled report (gitignored — generate locally) |

## Customising

The title block at the top of `main.tex` contains a placeholder
`Supervisor: [Name]`; replace this with the supervisor's name
before final submission. The author name is set to `Omar Shafiy`
to match the project's git config; change to your preferred
academic form if needed.

The figures live in `../docs/figures/` and are regenerated by
`scripts/build_figures.py` in the repo root. If you change a
figure's filename, update the corresponding `\includegraphics{...}`
in `main.tex`.

For a single-column "submission-style" layout, swap
`\documentclass[11pt, a4paper]{article}` for
`\documentclass[11pt, a4paper, twocolumn]{article}` (caveat:
several of the wider tables and figures will need width
adjustment to fit a column).
